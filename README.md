# Project Overview

This project demonstrates a comprehensive Student Portal system with the following modules, **all using real business logic and data flows** (no simulated prints):

## Student Portal
- View grades and export real academic transcripts
- Mark and fetch real attendance
- Check real placement eligibility, shortlist, and offer status
- Register for placement drives using actual registration logic

## Teacher Portal
- Upload student marks using real grading strategies (strategy pattern)
- Upload assignments/materials using real file upload logic
- Mark and display real attendance
- Export result summaries as real CSV/JSON files

## Administration Portal
- Enroll new students and teachers using real methods
- Create/update courses and map grading strategies
- Change grading policies mid-semester (real strategy pattern)
- Generate consolidated academic reports using real data

## Placement Cell Portal
- Add/update companies and drives with real eligibility and details
- Manage job profiles, compensation, and deadlines using real setters
- Register students for drives and check real offer/selection status
- Generate placement statistics and reports using real code

## Analytics Engine
- Generate all analytics and charts using real data and code:
  - GPA Trends
  - Dean's List
  - At-Risk Detection
  - Placement Offer Analysis
  - Company-wise Selection Metrics
